# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in mcp-taxonomy, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Send details via GitHub Security Advisory:
https://github.com/Carlos-Projects/mcp-taxonomy/security/advisories

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide a timeline for resolution.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Best Practices

- Keep the taxonomy up to date with evolving attack patterns
- Validate all adapter inputs and outputs
